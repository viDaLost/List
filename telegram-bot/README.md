# Бот Листа — Telegram Serverless

Этот каталог предназначен для собственного Serverless Telegram. Не нужны VPS, Cloudflare Worker для бота или обычный Bot API token. Официальная документация: https://core.telegram.org/bots/serverless

Сайт: https://list.vitaledanilov.workers.dev

Бот получает сообщения непосредственно от платформы Telegram. В SQLite Telegram хранится связь Telegram ID с автором. Сами статьи, изображения, резервные версии и хеши ключей браузера находятся в Cloudflare D1. В боте нет ChatGPT, Claude или других AI-запросов.

Команды:

- `/start` — одноразовая ссылка для доступа к собственным статьям, действует десять минут.
- `/start bind_…` — привязать браузер по ссылке из раздела «Доступ к статьям».
- `/articles` — последние двадцать собственных страниц, включая названия черновиков.

Групповые сообщения и сообщения от других ботов игнорируются. Указанный пользователем Telegram ID не принимается: берётся `message.from.id`, который предоставляет Telegram. Между ботом и сайтом проверяется отдельный серверный секрет. Ссылки привязки и восстановления используются один раз.

## Подключение

В BotFather откройте своего бота → **Serverless** → включите функцию → **CLI Access** → **Access token**. Нужен токен вида `app…:…`; обычный токен Bot API не подходит.

Из этого каталога:

~~~sh
npx --package=@tgcloud/cli@0.2.0 tgcloud login
npm run deploy
npm run migrate
~~~

Для CI используйте переменную `TGCLOUD_TOKEN`. CLI сам управляет `.tgcloud/`; этот каталог исключён из Git. Не копируйте токены в исходники, конфигурацию проекта или публичные сообщения.

После публикации нужно один раз выполнить приватный модуль `lib/setup` через CLI или BotFather Library с объектом `{ "bridgeSecret": "…" }`. Значение должно совпадать с секретом `TELEGRAM_BRIDGE_SECRET` в Worker. Модуль сохраняет его в SQLite Telegram и регистрирует настоящее имя бота на сайте. Не создавайте для setup публичный endpoint и не передавайте секрет в handlers/message.

Код подготовлен и проверяется локальными тестами. Публикация и проверка на настоящей платформе Telegram требуют CLI-токена владельца. Обновление файлов в GitHub само по себе не публикует бота.
