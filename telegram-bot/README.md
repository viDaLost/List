# Бот Листа — Telegram Serverless

Этот каталог предназначен для собственного Serverless Telegram. Не нужны VPS, Cloudflare Worker для бота или обычный Bot API token. Официальная документация: https://core.telegram.org/bots/serverless

Сайт: https://list.vitaledanilov.workers.dev

Бот получает сообщения непосредственно от платформы Telegram. В SQLite Telegram хранится связь Telegram ID с автором. Сами статьи, изображения, резервные версии и хеши ключей браузера находятся в Cloudflare D1. В боте нет ChatGPT, Claude или других AI-запросов.

Команды:

- `/start` — одноразовая ссылка для доступа к собственным статьям, действует десять минут.
- `/start bind_…` — привязать браузер по ссылке из раздела «Доступ к статьям».
- `/articles` — последние двадцать собственных страниц, включая названия черновиков.

Групповые сообщения и сообщения от других ботов игнорируются. Указанный пользователем Telegram ID не принимается: берётся `message.from.id`, который предоставляет Telegram. Между ботом и сайтом проверяется отдельный серверный секрет. Ссылки привязки и восстановления используются один раз.

## Подключение с телефона

В BotFather откройте своего отдельного бота → **Serverless** → включите функцию → **CLI Access → Access token**. Нужен токен `app…:…`, а не обычный Bot API token.

На сайте откройте доступ владельца, затем `/_list/telegram` (кнопка «Подключить Telegram» в редакторе). Вставьте токен в закрытую форму и нажмите «Подключить бота». Сервер обращается только к официальному `https://cloud.telegram.org`, проверяет существующий проект и версию, загружает подготовленные модули, применяет только добавления таблиц/колонок/индексов, настраивает приватную связь с сайтом и проверяет webhook. Чужой код, опасные миграции или сменившаяся версия останавливают операцию.

CLI-токен не сохраняется в базе, localStorage, репозитории или логах. Он передаётся по HTTPS вашему серверу и официальному API Telegram, а поле очищается после запроса. Серверный ключ связи с ботом остаётся отдельным секретом.

После успешного подключения откройте «Доступ к статьям» и привяжите браузер к боту. На других устройствах используйте `/start`.

## Ручная публикация через CLI

Из этого каталога:

~~~sh
npx --package=@tgcloud/cli@0.2.0 tgcloud login
npm run deploy
npm run migrate
~~~

CLI управляет `.tgcloud/`; этот каталог исключён из Git. Для связи с сайтом используйте закрытую форму владельца. Она запускает setup через приватный временный обработчик management API; временный обработчик не публикуется. Библиотеки `lib/` нельзя запускать напрямую командой `tgcloud run`. Не создавайте для setup публичный endpoint.

Код проверяется локальными тестами. Настоящая публикация требует токена владельца и завершается только после успешного ответа Telegram. Обновление GitHub само по себе бота не публикует.
