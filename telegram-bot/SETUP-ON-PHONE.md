# Настройка с телефона

1. Откройте официального @BotFather и выберите отдельного бота для Листа.
2. Включите **Serverless**.
3. Откройте **CLI Access → Access token**. Нужен токен `app…:…`, не обычный API token.
4. На сайте откройте личный доступ владельца и нажмите **Подключить Telegram** в меню редактора (страница `/_list/telegram`).
5. Вставьте CLI-токен в закрытую форму и нажмите **Подключить бота**. Токен не сохраняется и не попадает в репозиторий. Дождитесь сообщения с настоящим именем бота.
6. Откройте **Доступ к статьям → Открыть бота**, затем нажмите Start в Telegram.

После привязки для другого устройства отправляйте боту `/start`. Чужой код в выбранном боте автоматическое подключение не перезапишет.
