# Подключение с телефона

Владелец открывает BotFather → бот Листа → Serverless → CLI Access и копирует `Access token`.
На https://list.vitaledanilov.workers.dev/_list/telegram вставляет его в закрытую форму и нажимает «Подключить бота».
Токен нужен один раз для загрузки или обновления кода; пользователям он не нужен.

После успешной настройки отправьте боту `/start`. Будут три кнопки: «Мои статьи», «Новая статья», «Удалить статью».
Редактор автоматически подтверждает пользователя через Telegram. Вручную привязывать браузер, вводить ID или переносить ключи не нужно.
Статьи, созданные через Safari/Chrome, остаются в своём браузере и не смешиваются с Telegram-статьями.

Вставлять CLI-токен в чат, GitHub или код не нужно. Сайт не сохраняет его, поэтому для следующего обновления кода владельцу понадобится ввести его снова.
