# Настройка с телефона

1. Откройте официального @BotFather.
2. Создайте отдельного бота или выберите существующего.
3. Откройте **Serverless** и включите его.
4. Откройте **CLI Access → Access token**. Это отдельный токен вида `app…:…`, не обычный API token бота.
5. С этим токеном можно загрузить готовый каталог `telegram-bot` и применить его схему. После настройки сайта пользователи смогут привязать доступ кнопкой «Доступ к статьям».

Токен нельзя выкладывать в GitHub или отправлять в публичные чаты. Если раздел Serverless отсутствует, сначала проверьте его доступность для выбранного бота в BotFather.
