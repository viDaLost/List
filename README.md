# Лист

Мобильный сервис публикации статей: собственные адреса, оформление и карточки ссылок для мессенджеров.

- Редактор с текстом, заголовками, изображениями, цитатами, кнопками, чек-листами и раскрывающимися пояснениями.
- Краткая версия «Суть за минуту», оглавление и постоянные ссылки на разделы.
- Личные заметки читателя, отметки чек-листов и возврат к месту чтения в браузере.
- Публикации доступны для чтения без входа; для сохранения и публикации используется вход через ChatGPT.
- Жалобы, модерация, ограничения частоты действий и последние десять резервных версий каждой статьи.

## Работающий сервис

https://lista-studio.vitaledanilov.chatgpt.site

Сервер выполняется в **Cloudflare Workers**, статьи хранятся в **Cloudflare D1**, изображения и резервные версии — в **Cloudflare R2**. Текущее размещение и авторизация управляются через Sites. Этот репозиторий содержит исходный код; секреты и пользовательские данные в него не входят.

Панель владельца: /_list/admin. Доступ проверяется на сервере по подтверждённому аккаунту; адрес разрешённого аккаунта задаётся секретом **LIST_ADMIN_EMAILS**.

## Разработка и проверки

Требуется Node.js 24 или новее и pnpm.

~~~sh
pnpm install --frozen-lockfile
pnpm exec tsc --noEmit
node --test tests/api.test.mjs
pnpm run build
~~~

Приложение использует React, Vinext и Cloudflare Workers. Конфигурация D1/R2 находится в .openai/hosting.json; схема и последовательные миграции — в db/schema.ts и drizzle/.

Миграции уже опубликованных версий изменять нельзя: новые изменения добавляются отдельной миграцией. База для локальной разработки отделена от рабочей базы.

## Размещение в отдельном аккаунте Cloudflare

Текущий сборочный процесс создаёт Worker и его конфигурацию в dist/server/. Для переноса в другой аккаунт потребуются:

1. Собственные D1 и R2 с применением всех миграций из drizzle/.
2. Настройка секретов и адреса приложения.
3. Отдельная настройка авторизации: маршруты входа и заголовки oai-authenticated-user-* в текущем размещении предоставляет Sites. Один wrangler deploy в обычный аккаунт Cloudflare не создаёт эту интеграцию.

Не следует принимать заголовки идентификации непосредственно от посетителей или публиковать ключи Cloudflare в репозитории.

## Данные и восстановление

Публикации и черновики находятся в D1. Перед изменением, удалением или модерацией предыдущая версия статьи записывается в приватную часть R2. Панель владельца позволяет скачать резервную версию и восстановить её как черновик исходного автора. Хранятся последние десять версий каждой статьи.

Заметки, отметки чек-листов и место чтения хранятся только в браузере читателя и не синхронизируются с сервером.

## Проверки

Тесты выполняют реальные обработчики API с SQLite и тестовым адаптером объектного хранилища: проверяют изоляцию авторов, анонимное чтение, адреса и перенаправления, безопасный вывод, ограничения запросов, жалобы, модерацию, резервирование и восстановление.
